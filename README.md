# 조조전풍 SRPG

코에이 「조조전」에서 영감을 받은 웹 기반 턴제 SRPG 프로토타입.

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ 에 정적 빌드
```

## 현재 구현

- 격자 맵 + 지형(평지/숲/산/성채): 이동 비용, 물리 방어 계수
- 병종 5종: 기병 > 보병 > 궁병 > 기병 상성, 군주/책사는 중립
- 캐릭터 개성: 칭호, HP/MP/공/방/지력, 전용 책략·소지품
- 행동 메뉴: 공격 / 책략 / 아이템 / 대기
- 책략 시스템: MP 소모, 지력 기반 위력·명중률(지력 차), 지형 무시, 회복 책략
- 아이템: 회복약/약초/명차 (소모품)
- 반격 시스템: 사거리 안이면 위력 75%로 반격
- 적 AI: 책사는 책략 우선, 무장은 최적 대상 공격, 불가 시 접근
- 승리(적 전멸)/패배(아군 전멸) 판정

## 조작

- 좌클릭: 유닛 선택 → 이동 → 행동 메뉴에서 선택
- 우클릭: 취소 (이동 전 위치로 복귀)
- 책략 대상 위에 마우스: 명중률·예상 위력 미리보기
