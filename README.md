# 조조전풍 SRPG

코에이 「조조전」에서 영감을 받은 웹 기반 턴제 SRPG 프로토타입.

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ 에 정적 빌드
```

## 현재 구현 (전투 코어 MVP)

- 격자 맵 + 지형(평지/숲/산/성채): 이동 비용, 방어 계수
- 병종 상성: 기병 > 보병 > 궁병 > 기병
- 아군/적군 페이즈 턴제, 유닛별 이동 → 공격/대기
- 적 AI: 공격 가능하면 최적 대상 공격, 아니면 접근
- 승리(적 전멸)/패배(아군 전멸) 판정

## 조작

- 좌클릭: 유닛 선택 → 이동 → 공격 대상 선택
- 같은 유닛 재클릭: 제자리 행동
- 우클릭: 이동 취소
