# 조조전풍 SRPG

코에이 「조조전」에서 영감을 받은 웹 기반 턴제 SRPG 프로토타입.
Three.js 로우폴리 3D 아이소메트릭 뷰.

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ 에 정적 빌드
```

## 현재 구현

- **3D 렌더링 (Three.js)**: 아이소메트릭 오소 카메라, 로우폴리 지형(숲·산·성채 입체), 직업별 3D 캐릭터 모델(기마 유닛은 말+기수), 그림자, 이동 슬라이드 애니메이션
- **직업 시스템 (조조전 기반)**: 군주(조조)·친위대(하후돈)·궁기병(하후연)·황건적·적기병·적궁병·도사 — 직업이 상성 계열/기마 여부/사거리를 결정
- 격자 맵 + 지형(평지/숲/산/성채): 이동 비용, 물리 방어 계수 (기마는 산 진입 불가)
- 상성: 기병계 > 보병계 > 궁병계 > 기병계, 특수(군주/도사)는 중립
- **캐릭터 고유 특성(패시브)**: 조조 「패왕의 카리스마」(2칸 내 아군 데미지 +15%),
  하후돈 「외눈의 맹장」(잃은 HP 비례 데미지 증가), 하후연 「신궁」(25% 연속 사격),
  황건도사 「태평도 광신」(책략 위력 +20%) — 발동 시 전투 중 표시
- **캐릭터 외형 개성**: 하후돈 안대, 하후연 화살통·붉은 목도리, 조조 「曹」 군기
- 캐릭터 능력치: HP/MP/공/방/지력, 전용 책략·소지품
- 행동 메뉴: 공격 / 책략 / 아이템 / 대기
- 책략 시스템: MP 소모, 지력 기반 위력·명중률(지력 차), 지형 무시, 회복 책략
- 아이템: 회복약/약초/명차 (소모품)
- 반격 시스템: 사거리 안이면 위력 75%로 반격
- 적 AI: 책사는 책략 우선, 무장은 최적 대상 공격, 불가 시 접근
- 승리(적 전멸)/패배(아군 전멸) 판정

## 조작

- 좌클릭: 유닛 선택 → 이동 → 행동 메뉴에서 선택
- 우클릭: 취소 (이동 전 위치로 복귀)
- 책략 대상 위에 마우스: 명중률·예상 위력 미리보기
